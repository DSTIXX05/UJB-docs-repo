# Admin Dashboard

![User portal screenshot](/img/ss/image4.png)

The Dashboard serves as the central data hub for UJB Mart, providing a bird's-eye view of your daily logistics and financial metrics.

## Key Features & Metrics

    - **Date Filtering:** Filter all analytical data by defining specific start and end dates via the date-picker option at the top of the screen.
    - **High-Level Metrics:** View real-time calculations for:
        - Total Revenue
        - Total Orders & Orders in Progress Today
        - Total Active Riders & Registered Customers
    - **Operational Charts:** Track revenue trends and hourly order metrics via the central analytical graphs.
    - **Live Order Summary:** Located at the bottom of the dashboard, this interactive table displays a real-time summary of incoming orders alongside their immediate status.
