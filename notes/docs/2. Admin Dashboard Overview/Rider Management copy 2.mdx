# Rider Management

![User portal screenshot](/img/ss/image6.png)

The Riders Management interface displays a holistic index of dispatch personnel paired with their real-time performance and system status metrics.

## Managing Individual Riders

![User portal screenshot](/img/ss/image7.png)
Clicking the 3-dot action menu on any rider's record launches their profile card, enabling the following management functions:

![User portal screenshot](/img/ss/image8.png)

- **Rider Profiling:** View comprehensive contact information, Address, Vehicle Type, Vehicle Color, and Max. Capacity.
- **App State & Status:** Monitor if a rider is Online/Offline or Active/Suspended.
- **Performance Metrics:** View historical metrics like Completed Orders and Date Joined.
- **Administrative Actions:**
  - Review specific Assignments.
  - Dispatch an in-app text via Send Message.
  - Toggle operational modes via the dropdown menu (Offline, Online, Busy).
  - Revoke platform access instantly using the Suspend button.
