# Pool & Resource Aggregation

Because UJB Laundry Mart operates on a complex network of dynamic variables, the Pool module functions as a centralized diagnostic dashboard where active system assets are tracked in real-time.

## Stats

Provides a high-level overview of overall system health:

- Performance Data: Track aggregates including Total Deliveries, Total Pickups, Completed Orders, and user-submitted Average Ratings.
  ![User portal screenshot](/img/ss/image17.png)

## Pool Dynamics

- Riders Metric: Displays a summary of total active dispatch personnel versus the subset currently free and available for routing.

## Activity & Riders Tabs

- Activity: A specialized log showcasing all Pending Assignments currently waiting to be accepted or picked up by riders. Admins can drill down using the 3-dot action menu to inspect structural assignment data.
  ![User portal screenshot](/img/ss/image18.png)

- Riders in Pool: A real-time ledger of available riders on standby. Admins can view, edit profiles, or execute suspensions directly from this screen.
  ![User portal screenshot](/img/ss/image19.png)
