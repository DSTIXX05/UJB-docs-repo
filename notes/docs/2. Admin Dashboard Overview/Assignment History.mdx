# Assignment History

![User portal screenshot](/img/ss/image11.png)

The Assignments portal tracks order dispatch routing.

- **Tracking Mechanics:** Admins can oversee orders that have been assigned to riders either manually by an administrator or automatically by the backend system's matching architecture.
- **State Tracking:** Real-time logging of whether an assignment is currently Pending (awaiting acceptance) or Accepted by the designated rider. he dropdown menu (Offline, Online, Busy).
