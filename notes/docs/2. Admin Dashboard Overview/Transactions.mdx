# Transactions

![User portal screenshot](/img/ss/image20.png)

The Transaction ledger provides a complete audit trail of all financial checkouts attempted on the platform.

- Status Parameters: Every transaction event is flagged with an immutable status indicator: Success, Failed, or Expired.
- Audit Vectors: Cross-reference transaction IDs with specific Order IDs, customer names, payment gateways, and time vectors.
