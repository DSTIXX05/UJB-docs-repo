# Extras (Communications)

The Extras panel handles outreach and engagement across the platform.

- Message Tab: Send structured, targeted in-app text messages. Select the message type (Customer, Rider, Custom, or Admin), fill out the subject line, compose your text body, and hit Send.
- Notification Tab: Create and deploy system-wide push notifications to instantly alert specific user groups regarding app updates or promotional campaigns.
