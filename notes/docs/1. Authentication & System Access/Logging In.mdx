# Logging In

![User portal screenshot](/img/ss/image2.png)
To access the administrative backend, navigate to the official **[login](https://portal.ujblaundry.com/)** portal.

- **Portal URL:** [https://portal.ujblaundry.com/](https://portal.ujblaundry.com/)
- **Action:** Enter your registered administrative Email and Password into the authentication fields, then click Sign In.

💡 System Note: Upon successful authentication, the system will immediately redirect you to the main Admin Dashboard interface.
